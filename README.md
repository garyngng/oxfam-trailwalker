# 毅行者全段分析

樂施毅行者 2026 由西貢北潭涌去屯門哈羅香港國際學校。呢個參考把約 100 公里拆成小段，標明上山、落山、平路、可唔可以跑，同埋東壩、雞公山、針山、草山、大帽山等位置。

到達時間用你張 18–28 小時表嘅分鐘，釘喺 2026 官方 GPX 嘅檢查站。表上有幾段里數同實測差好遠，尤其係西灣同尾段去哈羅，頁面有寫明。

朋友嘅操練手記用嚟標樓梯、士多付款同廁所。嗰啲鐘點係練習當日，唔係比賽配速。

## 點用

```bash
npm install
npm run dev
```

然後開 [http://127.0.0.1:4179](http://127.0.0.1:4179)。

可以揀 18 至 28 小時，同 2026 四個起步時間。尾段如果想按實際大約 13 公里計，而唔係表上 6.9 公里，撳「尾段改用實際里數」。

## 資料

- 距離同高度：樂施會 2026 100 公里 GPX
- 路線同麥徑唔同嘅三位：西灣沙灘（M031–M033）、大帽山道落扶輪公園、元荃古道去哈羅。見到標距柱 M175 就係行錯
- 樓梯級數、士多、廁所：操練手記
- 重新計數：`python3 scripts/build_course.py /path/to/route.gpx`

路線同年會改。關門時間同補給以樂施會當年手冊為準。
